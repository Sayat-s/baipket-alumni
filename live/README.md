# Baipket Live: Акселерация диагностикасы (Google Meet үшін)

Бір `index.html` файл, сервер де, интернет те керек емес. Miro сияқты шексіз бордта камера фреймнен фреймге ұшады.
Сахналар (13): Ашылу → Профиль → Проблемы → Уровень → Расчёт (индекс совпадения + личная рекомендация) → Акселерация → Программа → Как проходит курс → Pre-Sales → Бонусы → Гарантия → Топ-5 и новое → Финал.

## Қалай қолданады

1. Chrome-да `live/index.html` ашасың (немесе `cd live && python3 -m http.server 8000`, содан `http://localhost:8000`).
2. Басқа терезеде **`O`** басасың. Бұл **режиссер пульті**: сценарий мәтіні, орын санағыш, сахна тізімі. Пультті лид көрмейді.
3. Google Meet: «Презентация» → **Chrome вкладкасы** → тек сахна вкладкасын таңдайсың. Дыбыс керек болса, «Вкладканың дыбысын бөлісу» белгісін қой.
4. Сахнада: `→`/`Space` келесі, `←` артқа, `1–9` сахнаға секіру.

## Пернелер (сахна терезесі)

| Перне | Не істейді |
|---|---|
| `→` / `Space` / `←` | келесі / артқа |
| `A` | **Авто**: аты бар курсор диагностиканы өзі өтеді (лид шеше алмаса) |
| `R` | сахнаның анимациясын қайталау |
| `Shift+R` | жаңа лид: жауаптар тазаланады |
| `S` | дыбыс эффектілері (әдепкіде өшірулі) |
| `U` | интерфейс чиптерін жасыру (тышқан қозғалмаса олар өздігінен өшеді) |
| `F` | fullscreen |
| `O` | режиссер пультін ашу |

## Сәйкестік индексі қалай есептеледі (экранда да көрсетіледі)

`индекс = 40% профиль + 30% знакомые проблемы (0–4) + 30% разрыв ((5 − уровень) орташасы)`, ең көбі 98%.
Бұл жауаптарға негізделген бағдар, нәтиже кепілдігі емес (экранда да жазылған).

## Деректерді өзгерту

`index.html` ішіндегі `PROFILES`, `PAINS`, `AXES`, `PROGRAM`, `NOTES` массивтері мен `DEADLINE` (Pre-Sales аяқталу уақыты, қазір 10.11.2026 23:59 Алматы) өзгертіледі.
Бағалар `#f8` секциясында. «Қалған орын» санын пультте `− / +` арқылы нақты жағдайға сай жаңартып отыр.

## Сату пульті (`live/sales.html`)

Толық қазақша қоңырау сценарийі: 7 кезең (рамка → нәтиже мен мақсат → мәселе → диагностика → шешім → оффер → гарантия және жабу), әрқайсысында «Айтамыз / Сұраймыз / Есте сақта».
- Әр кезеңде «Экранға шығару» батырмасы: сахна терезесін (`index.html`) сол сәтте керек сахнаға ұшырады. Екі терезе бір браузерде ашық болуы керек.
- Оң жақта лид карточкасы (нәтиже, мақсат, кедергі, пакет, шешім, Pre-Sales орны). «Қорытындыны көшіру» CRM-ға салуға дайын мәтін береді. Деректер браузерде (localStorage) сақталады.
- Төменде 6 қарсылыққа жауап. Лидтің өз сөзі жауаптарға автоматты қойылады.
- Кезең таймері жоспардан асса қызарады. Пернелер: `←` `→` кезең, `Space` сахнаны алға жылжыту.

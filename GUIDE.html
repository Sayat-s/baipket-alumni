BAIPKET ALUMNI CHALLENGE

Нұсқаулық: іске қосудан күнделікті жұмысқа дейін

Қысқа және нақты. Қадамдар ретімен жүреді. Терминалсыз, тек батырма басу арқылы тұрақты сайт жасау жолы 2-бөлімде.

0. Қазір не бар

  • Түлектің беті: тіркелу, Alumni Pass картасы, XP, жол картасы, дос қосу, WhatsApp-қа дайын хабар, 2 дос қосқанда екі модуль ашылады.
  • Достың беті (/r/КОД): Baipket туралы экскурсия, 10 поток, қауымдастық, нөмір қалдыру немесе WhatsApp-қа жазу. Баға жоқ.
  • Админ (/admin): лидтер, статус, бонус, «Рақмет» батырмасы, мәтіндерді өзгерту, CSV.
  • amoCRM: лид «Baipket • Рефералдар» воронкасына автоматты түседі, статус екі жаққа жаңарады.
Не жоқ / өзіңіз істейтін нәрсе:
  • Сайтты интернетке шығару (1 немесе 2-бөлім).
  • amoCRM токені мен webhook (3-бөлім).
  • Нақты кейстер мен фото (админде «Baipket туралы»).
  • WhatsApp хабарын автоматты жіберу жоқ: түлек «Жіберу» батырмасын басады.

1. Бүгін тест үшін (уақытша сілтеме)

Тек сыналатын уақытта. Макбук ұйықтаса, сілтеме өшеді, әр іске қосқанда сілтеме жаңа болады.

cd ~/Downloads/baipket-alumni
ADMIN_PASSWORD=ұзын-пароль bash share.sh

Terminal-да Достарға жіберілетін сайт: https://сөз-сөз-сөз.trycloudflare.com деген жол шығады. Осы сілтемені ашыңыз. trycloudflare.com сайтының өзі (Cloudflare жарнамасы) сіздікі емес.

Админ: сол сілтеме + /admin.

2. Тұрақты сайт (терминалсыз)

Мақсат: сайт 24 сағат жұмыс істесін, макбук өшсе де. Шамамен 20–30 минут. Тіркеу керек: GitHub және Render. Render-дегі жоспардың бағасын сайттан тексеріңіз (деректер сақталатын диск ақылы жоспарда ғана бар).

2.1 Кодты GitHub-қа салу

  1. github.com сайтында тіркеліңіз → жоғарғы оң жақта + → New repository. Аты: baipket-alumni. Private таңдаңыз → Create.
  2. Макбукте baipket-alumni папкасын ашыңыз. Ішіндегі bin папкасы болса, өшіріңіз (ол 19 МБ, керек емес). data папкасын да өшіріңіз.
  3. GitHub бетінде uploading an existing file сілтемесін басыңыз. Папканың ішіндегі бәрін (server.mjs, public, lib, Dockerfile, render.yaml…) тінтуірмен сүйреп тастаңыз → Commit changes.

2.2 Render-де іске қосу

  1. render.com → тіркеліңіз (GitHub-пен кіруге болады).
  2. New → Blueprint → GitHub репозиторийін таңдаңыз. Render render.yaml файлын өзі оқиды.
  3. Сұралған мәндерді толтырыңыз:
    ADMIN_PASSWORDұзын құпия пароль (админге кіру)
    PUBLIC_URLқазірше бос қалдырмаңыз: Render берген мекенжайды (https://....onrender.com) жазыңыз, сайт іске қосылған соң
    AMO_TOKEN3-бөлімнен алған токен (қазір бос қалдыруға болады)
  4. Deploy аяқталған соң сайт мекенжайы шығады. PUBLIC_URL дұрыс екенін тексеріңіз. Сәйкес келмесе, Environment бөлімінде өзгертіп, қайта іске қосыңыз.
  5. Диск (Disk) міндетті: /data жолы. Онсыз сервер қайта қосылғанда түлектер мен лидтер жоғалады.

2.3 Өз домен

  1. Домен сатып алыңыз (ps.kz, hoster.kz, Namecheap, Cloudflare). Бағасын сайттан тексеріңіз.
  2. Render → сервис → Settings → Custom Domains → доменіңізді қосыңыз. Render көрсететін DNS жазбаларын домен тіркеушісінде қойыңыз.
  3. HTTPS автоматты қосылады. Сосын PUBLIC_URL=https://сіздің-доменіңіз етіп өзгертіңіз.

Render интерфейсіндегі атаулар өзгеруі мүмкін. Бір қадамда жолыңыз табылмаса, экранның суретін жіберіңіз.

3. amoCRM қосу

  1. amoCRM → Баптаулар → Интеграциялар → Интеграция құру → Жеке интеграция.
  2. Кілттер мен қолжетімділік → Ұзақ мерзімді токен жасау (мерзімін ұзақ етіп). Токенді көшіріп алыңыз, ол бір рет қана көрсетіледі. Токенді ешкімге, оның ішінде маған да, жібермеңіз.
  3. Render → Environment → AMO_DOMAIN=aksamowhitelabelkz.amocrm.ru және AMO_TOKEN=токен. Сақтап, қайта іске қосыңыз.
  4. Сайт админі → «amoCRM» блогы → Воронканы құру/тексеру. Сонда «Baipket • Рефералдар» воронкасы пайда болады.
  5. Екі жақты байланыс: админдегі webhook мекенжайын көшіріп, amoCRM-де «сделка статусы өзгергенде» оқиғасына қойыңыз. Енді сделка «Успешно реализовано» болса, сайтта «төлем расталды» болады.
  6. Тест: өз қосымша нөміріңізбен лид жасаңыз. Ол amoCRM-де воронкада көрінуі керек.

4. WhatsApp → amoCRM

  • Достың беті «WhatsApp-та жазу» батырмасын көрсетеді. Нөмір CONTACT_PHONE env мәнінен алынады (қазір +7 706 608 80 80, қате болса, өзгертіңіз).
  • Сол нөмір amoCRM-ге WhatsApp интеграциясымен қосылса, хабар лид болып түседі. Хабарда «шақыруымен» сөзі бар, оны amoCRM автоматизациясымен «Рефералдар» воронкасына бағыттауға болады.
  • WhatsApp хабарын автоматты жіберу керек болса, WhatsApp Business API (Wazzup сияқты ақылы сервис) қосу керек. Қазір түлек «Жіберу» батырмасын өзі басады.

5. Күнделікті жұмыс (админ)

Админ: сайт/admin. Пароль: ADMIN_PASSWORD.

  1. Жаңа лид келді. Админде және amoCRM-де көрінеді. Менеджер WhatsApp-қа жазады.
  2. Сөйлесу барысында amoCRM-де сделканы жылжытыңыз (Байланыстық → Қызығушылық → Төлем күтеміз). Түлектің бетінде жолақ жылжиды.
  3. Төлем түскенде: сделканы «Успешно реализовано» етіңіз. Сайтта «Төлем расталды» болады.
  4. Рақмет айту: админде сол лидтің жанындағы 🙏 Рақмет басыңыз, WhatsApp түлекке дайын хабармен ашылады.
  5. Бонус төленгенде «Бонус төленді» белгісін қойыңыз. Түлек бетінде «Бонус төленді ✅» көреді.

Өзгертуге болатындар (админде, кодсыз)

  • Бағалар мен бонус. Қанша дос қосқанда модуль ашылатыны.
  • WhatsApp хабар мәтіні. «Рақмет» мәтіні.
  • Модуль мәтіндері.
  • «Baipket туралы»: неше поток, ұран, қауымдастық, кейстер (формат: Аты | Кім | Нәтиже). Кейстер жазылса, достың бетінде бөлім пайда болады.

6. Тарату алдындағы тексеру

  1. Сайт өз мекенжайымен басқа телефонда ашылады ма?
  2. Тест түлек тіркеліп, 2 дос қосқанда екі модуль ашылды ма?
  3. WhatsApp достың нөміріне дайын хабармен ашылды ма, сілтемесі https://... па?
  4. Сілтеме WhatsApp-та превьюмен (сурет, тақырып) көрінді ме?
  5. Лид amoCRM-де «Рефералдар» воронкасында пайда болды ма?
  6. Сделканы «Успешно реализовано» еткенде сайтта статус жаңарды ма?
  7. Админде «🙏 Рақмет» батырмасы WhatsApp-ты ашты ма?
  8. Құпиялық мәтінін заңгер немесе жауапты адам тексерді ме? (Қазіргі мәтін қысқа үлгі.)
  9. Нақты кейстер мен фото қосылды ма?

# Бот клана Учиха 🔥

Телеграм-бот для прожарок и приколов в дружеском чате.

## Запуск
1. В Telegram найди **@BotFather** → `/newbot` → получи токен.
2. **Важно:** там же `/setprivacy` → выбрать бота → **Disable** (иначе бот не видит обычные сообщения и не сможет вклиниваться сам).
3. Добавь бота в группу.
4. Локально:
   ```
   pip install -r requirements.txt
   cp .env.example .env   # вставь токен
   export $(cat .env | xargs) && python bot.py
   ```
5. Допиши в `members.json` реальные приколы про каждого (`facts`) и свои шутки в `content.py`.

С `ANTHROPIC_API_KEY` бот генерит свежие шутки с учётом `facts`, без ключа берёт заготовки.

## Самый простой запуск
```
cd uchiha-bot
./run.sh
```
Скрипт сам всё установит, спросит токен (скрытый ввод), сохранит его в `.env` и запустит бота.

## Қазақша нұсқа (v2)
- Бот қазақша сөйлейді, «ублюдок / далбаң / черт екенсің / ал че там» қолданады.
- `members.json` ішінде әркімнің `role` өрісін толтыр: `"монтажер"` немесе `"продажник"` — бот жұмысына қарай тиісетін болады.
- Жұма түні «үй жинайық» + кезек (кім не істейді): топта бір рет `/sethome` жаз. Уақыты: `HOUSE_TIME=23:30` (Алматы уақыты, әдепкі 22:00). Ботты сол кезде қосып қою керек (комп өшіп тұрса, жібермейді).
- Тексеру үшін: `/uy` — кезекті бірден шығарады, `/chetam` — бәріне «ал че там».

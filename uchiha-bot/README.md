# Бот клана Учиха 🔥

Телеграм-бот для прожарок и приколов в дружеском чате.

## Запуск
1. В Telegram найди **@BotFather** → `/newbot` → получи токен.
2. **Важно:** там же `/setprivacy` → выбрать бота → **Disable** (иначе бот не видит обычные сообщения и не сможет вклиниваться сам).
3. Добавь бота в группу.
4. Локально:
   ```
   pip install -r requirements.txt
   cp .env.example .env   # вставь токен
   export $(cat .env | xargs) && python bot.py
   ```
5. Допиши в `members.json` реальные приколы про каждого (`facts`) и свои шутки в `content.py`.

С `ANTHROPIC_API_KEY` бот генерит свежие шутки с учётом `facts`, без ключа берёт заготовки.
